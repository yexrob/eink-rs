- 日期：2026-10-21
- 状态：已实施

## 背景

[002](002-inkui-port-plan.md) 的测试发现 ink-rs 把一次读到的 `"\r\r"` 当成一段文本，TextInput 把 `\r` 插进值里。ink-rs 的 [061](https://github.com/yexrob/ink-rs/blob/main/docs/decisions/061-split-cr-tab.md) 把 CR 和 TAB 拆成单独的事件，[062](https://github.com/yexrob/ink-rs/blob/main/docs/decisions/062-release-0-1-3.md) 发布 0.1.3。用户答「2. 发」时，Claude 说过发完升级 eink-rs 的依赖。

## 决策

以下由 Claude 按用户的授权（「2. 发」）定：

- 依赖改成 `ink-rs = "0.1.3"`。
- 删掉 `docs/design.md` 测试一节里关于一次读取不拆键的说明。测试里用方向键隔开的按键不改：它们在 0.1.3 下成立，改了不增加覆盖。

## 方案

主 agent 自己做：改 `Cargo.toml` 和 `Cargo.lock`，删说明，跑三种 feature 组合的测试和 clippy，提交。推送等用户批准。

## 结果

无 feature 113 个、`--features cli` 116 个、`--workspace --all-features` 117 个测试通过，clippy 通过。
